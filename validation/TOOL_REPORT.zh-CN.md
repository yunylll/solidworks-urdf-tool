## 关键修正

1. 原型只调用安装目录 DLL；本版本编译独立核心并采用 JSON 作为跨进程接口，避开嵌入 COM 泛型类型的程序集边界限制。
2. Pack and Go 即使只读打开源模型也可能保存元数据。正式工具先复制文件，仅对快照执行打包，避免源文件修改。
3. 简单的保存依赖列表可能包含旧配置或导入缓存。提供已保存活动模型的组件/配置/质量清单，只有副本几何通过核验才继续。
4. 反序列化旧配置后恢复组件持久引用；空组件 Link 不能被当成完整模型计算质量。
5. 修复核心坐标框架节点跳过子树、错误弹窗阻塞、空属性值处理及关节成功判断。
6. 强制使用 SI 质量单位，采用 2026 的 MassProperty2 做整体质量核验，保存并恢复相关 STL 参数。
7. 保留持久 JSON 结果、日志、超时处理、私有进程身份核验及工作进程终态检查。

## 2.1 更新（2026-10-08）

根据在一个大型真实装配体（约 700 个零件、18 个 Link）上使用 2.0 的情况所做的改动：

| 项目 | 改动 | 验证 |
| --- | --- | --- |
| 只检查不导出 | check / check_only 跑到 Link 坐标系和关节即停 | 大型真实装配体，复用准备好的副本：5 分钟解析出 17 个关节（完整导出约 38 分钟） |
| 复用副本 | reusable_model 跳过只读打开和 Pack and Go；导出失败后也保留 | 含虚拟零件的示例机械臂；一个大型真实装配体（含 3D Interconnect 组件） |
| 进度 | 阶段、步数（STL n/N、Link、质量属性）、已用/空闲秒数、带时间戳的日志 | 离线任务测试；回归运行 |
| 取消 | cancel / cancel_export_job，清理和设置恢复与失败时相同 | 排队中和运行中的任务；MCP 客户端 |
| 卡住判定 | 既无进度、SolidWorks 也不占 CPU 时才停止（默认 900 秒）；总上限 14400 秒 | 空闲、忙碌、持续有进度的测试进程 |
| 等待 | get_export_job(wait_seconds) / job --wait，任务结束立即返回 | 离线测试；MCP 客户端 |
| 报错 | 配置、Pack and Go、打开、质量、URDF 检查都给出对象、期望值和实际值；error.stage | 拼错组件名：报错写明 Link 和相近的组件名 |
| 配置 | joint.mimic、world（朝上轴、落地、居中）；无保存配置时生成骨架；validate_urdf 不限路径 | 离线后处理测试；带 mimic 和 Z 轴朝上 world 的机械臂导出 |
| 未保存修改 | 提示保存或关闭不保存；use_saved_files 按已保存文件导出 | 代码审查（需交互会话才能实测） |
| 提速 | STL 导出后的逐个恢复可见性（该大型装配体上占 38 分钟中的 10 分钟）在丢弃的私有副本上跳过 | 回归导出 |

测试中发现并修正两处缺陷：STL 设置在导出改变了尺寸的文档中比较（coarse/fine 质量下偏差随文档变化）；复用副本时误拒虚拟零件和 3D Interconnect 组件。scripts/test_cad_regressions.py 会生成含虚拟零件的示例机械臂副本，覆盖虚拟零件、共用原点的关节、只检查模式、复用、进度、mimic/world 和报错信息。

## 使用与范围

常规使用见 [README](../README.zh-CN.md)。本机已注册 MCP 服务；重新加载 MCP 配置后可在 Codex 的工具目录中使用。

本版本提供原项目传统 ROS URDF/STL 包。JSON 编辑覆盖 Link 树、组件归属、坐标系、固定/连续/转动/平移关节及限位、阻尼/摩擦、坐标框架。mimic 关节和 world 根坐标自 2.1 起可配置；外观编辑、ROS 2 启动脚本和 MJCF/USD 尚未作为本版本的独立功能暴露。真实执行器参数与机械关节意图需要用户或经审查的设计数据。

一切正式模型应在目标 ROS/仿真环境复核。超时或中断任务明确失败，不能将其部分输出视为成功。
