# SolidWorks URDF 2026 Tool 2.0.0 開発・受入レポート

[English](TOOL_REPORT.md) | [简体中文](TOOL_REPORT.zh-CN.md) | **日本語**

日付：2026-10-07。目標：SolidWorks 2026 に対応し、コードや MCP から呼び出せるツールへと開発を進めること。

結論：**動作するローカルツールを実装し、検証しました。** ネイティブのエクスポートコアは上流のソースからビルドし、正式なエントリポイントは分離したスナップショット経由でモデルを処理します。MCP サービスはローカルの Codex に登録済みで、起動・呼び出しのチェックに合格しています。

## 主な修正

1. 試作版はインストールフォルダの DLL を呼ぶだけでした。このバージョンでは独立したコアをビルドし、プロセス間のインターフェースに JSON を採用して、埋め込み COM ジェネリック型によるアセンブリ境界の制約を回避しました。
2. Pack and Go は、元モデルを読み取り専用で開いてもメタデータを保存することがあります。正式なツールは先にファイルをコピーし、パッケージ化をスナップショットに対してのみ行うことで、元ファイルの変更を防ぎます。
3. 単純な保存済み依存リストには、古い構成やインポートキャッシュが含まれることがあります。保存済みアクティブモデルのコンポーネント/構成/質量の一覧を提供し、コピーのジオメトリが検証に合格した場合にのみ処理を続けます。
4. 旧設定をデシリアライズした後にコンポーネントの永続参照を復元します。コンポーネントが空の Link を完全なモデルとして質量計算に使ってはいけません。
5. コアにおける、座標フレームノードの子ツリーのスキップ、エラーダイアログによるブロック、空のプロパティ値の扱い、ジョイントの成否判定を修正しました。
6. SI 質量単位を強制し、全体質量の検証に 2026 の MassProperty2 を使い、関連する STL パラメータを保存・復元します。
7. 永続的な JSON 結果、ログ、タイムアウト処理、プライベートプロセスの身元確認、ワーカーの終了状態チェックを維持しています。

## 2.1 更新（2026-10-08）

大規模な実アセンブリ（約 700 パーツ、18 Link）で 2.0 を使った結果に基づく変更です。

| 項目 | 変更 | 検証 |
| --- | --- | --- |
| チェック専用 | `check` / `check_only` は Link 座標系と関節まで実行して停止 | 大規模な実アセンブリ、準備済みコピーを再利用：17 関節を 5 分で解決（完全エクスポートは約 38 分） |
| 再利用 | `reusable_model` で読み取り専用オープンと Pack and Go を省略。失敗したエクスポート後も保持 | 仮想部品を含むサンプルアーム、大規模な実アセンブリ（3D Interconnect コンポーネントを含む） |
| 進捗 | 段階、ステップ数（STL n/N、Link、質量特性）、経過/アイドル秒数、タイムスタンプ付きログ | オフラインのジョブテスト、回帰実行 |
| キャンセル | `cancel` / `cancel_export_job`。後片付けと設定復元は失敗時と同じ | 待機中・実行中のジョブ、MCP クライアント |
| 停滞判定 | 進捗も SolidWorks の CPU 作業もないときだけ停止（既定 900 秒）。総上限 14400 秒 | アイドル・ビジー・進捗ありのテストプロセス |
| 待機 | `get_export_job(wait_seconds)` / `job --wait` はジョブ終了と同時に戻る | オフラインテスト、MCP クライアント |
| エラー | 設定、Pack and Go、オープン、質量、URDF の各チェックで対象・期待値・実際の値を表示。`error.stage` | コンポーネント名の誤り：Link と似た名前を表示 |
| 設定 | `joint.mimic`、`world`（上向き軸・接地・中心合わせ）。保存済み設定がなければテンプレート。`validate_urdf` は任意のパス | オフラインの後処理テスト、mimic と Z 軸上向き world 付きのアームのエクスポート |
| 未保存の変更 | 保存するか保存せずに閉じるよう案内。`use_saved_files` で保存済みファイルをエクスポート | コードレビュー（実測には対話セッションが必要） |
| 高速化 | STL エクスポート後の表示状態の復元（この大規模アセンブリでは 38 分中 10 分）を、破棄するプライベートコピーでは省略 | 回帰エクスポート |

テスト中に見つかった 2 つの不具合を修正しました：エクスポートでサイズが変わったドキュメント上で STL 設定を比較していたこと（coarse/fine 品質では偏差がドキュメントに従う）、再利用コピーで仮想部品と 3D Interconnect コンポーネントを拒否していたことです。`scripts/test_cad_regressions.py` は仮想部品を含むサンプルアームのコピーを作り、仮想部品、原点を共有する関節、チェック専用モード、再利用、進捗、mimic/world、エラーメッセージを検証します。

## 使い方と対象範囲

通常の使い方は [README](../README.ja.md) を参照してください。MCP サービスはローカルに登録済みで、MCP 設定を再読み込みすると Codex のツールカタログで使えます。

このバージョンが出力するのは、元プロジェクトと同じ従来型の ROS URDF/STL パッケージです。JSON 編集は、Link ツリー、コンポーネントの割り当て、座標系、fixed/continuous/revolute/prismatic ジョイントとそのリミット、ダンピング/摩擦、座標フレームを対象とします。mimic 関節と world フレームは 2.1 から設定できます。外観編集、ROS 2 の起動スクリプト、MJCF/USD は、このバージョンではまだ独立した機能として公開していません。実際のアクチュエータのパラメータや機構上のジョイントの意図は、ユーザーまたはレビュー済みの設計データから与える必要があります。

正式なモデルは、必ずターゲットの ROS/シミュレーション環境で再確認してください。タイムアウトまたは中断したジョブは明確に失敗として扱われ、その部分的な出力を成功とみなしてはいけません。
